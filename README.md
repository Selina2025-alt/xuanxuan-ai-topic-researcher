# 萱萱｜AI 选题研究员

这是“萱萱｜AI 选题研究员”的公开静态展示站。

## 安全边界

- 不连接 Hermes、飞书、模型或任何 API。
- 不包含 App Secret、API Key、Token 或内部标识。
- 不包含真实选题库地址、研究资料链接或本地路径。
- 模拟交互仅切换内置演示数据，不保存访客输入。
- 页面中的规模化指标为视觉演示数据，不代表真实业务数据或实际运行结果。

## 本地预览

使用任意静态文件服务器打开当前目录即可。

## GitHub Pages

仓库创建后，可以将 GitHub Pages 的发布源设置为 `main` 分支根目录。入口文件为 `index.html`。
